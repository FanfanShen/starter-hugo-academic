## 一、介绍

Chat2DB 是一款AI first的数据管理、开发、分析工具，它的核心是AIGC（Artificial Intelligence Generation Code）能力，它可以将自然语言转换为SQL，也可以将SQL转换为自然语言，也可以自动生成报表，极大的提升人员的效率。通过一个产品可以实现数据管理、数据开发、数据分析的能力，即使不懂SQL的运营业务也可以使用快速查询业务数据、生成报表能力。[chat2db官网](https://chat2db-ai.com/)

Chat2DB有三个版本，community，local和pro版本，本文主要介绍免费的community版本的安装及其使用方法。

## 二、安装方法

1. [点击进入gihub下载最新release版本](https://github.com/OtterMind/Chat2DB/releases)，单击Chat2DB-Community-5.3.6.msi（可选择最新版本，MSI为Windows系统）进行下载。
2. Win+X → 选择 **终端 (管理员)** / **命令提示符 (管理员)** / PowerShell 管理员
3. 在命令行中，找到文件下载位置，执行：
```
msiexec /i "Chat2DB-Community-5.3.6.msi" INSTALLDIR="D:\Software"   //安装到指定路径D:\Software
```
4. 桌面双击即可启动chat2db

## 三、Chat2db连接数据库

**步骤一：SQLserver的配置准备工作，SQL Server 配置管理器，开启 TCP/IP**
1. 打开 **SQL Server 配置管理器**
2. 左侧展开：**SQL Server 网络配置 → MSSQLSERVER 的协议**
3. 在右侧找到 **TCP/IP**，右键 → **启用**
> 会弹出提示：修改后需要重启 SQL 服务才生效
4. 双击 TCP/IP，切换到【IP 地址】标签页
   - 滚动到最底部 `IPAll`
   - **TCP 端口**：填写 `1433`
   - **TCP 动态端口**：清空，保持空白
   - 上方所有 IP（IP1,IP2…），把【已启用】全部改为 `是`
5. 点击【确定】保存
6. 左侧切换到【SQL Server 服务】，右键 `SQL Server(MSSQLSERVER)` → **重启**

**步骤二：验证端口是否监听,管理员身份打开 CMD，执行：**

```
netstat -ano | findstr "1433"
```
正常：会出现 `0.0.0.0:1433` 这一行，代表端口监听成功

**步骤三：在SQLserver的SSMS执行脚本开启sa账号：**
```
ALTER LOGIN sa ENABLE;
ALTER LOGIN sa WITH PASSWORD='123456';
GO
```

**步骤四：Chat2DB连接数据库**

- 打开Chat2DB，选择工作台，然后选择左上角的+号，新建连接，选择SQLserver，安装如下方式配置连接

| 项目       | 值                               |
|----------|---------------------------------|
| 主机       | localhost                       |
| 端口       | 1433                            |
| Instance | 空                               |
| 身份验证     | 用户名和密码                          |
| 用户名      | sa                              |
| 密码       | 123456                          |
| URL      | jdbc:sqlserver://localhost:1433 |
| 驱动       | mssql-jdbc-11.2.1.jre17.jar     |

- 填好后，点击左下角的测试连接，如果提示测试通过，即表示成功。

**步骤五：Chat2DB的AI对话访问数据库的能力**

1. 点击左边的对话，新建对话功能；
2. 在对话框右下角选择“自定义模型”；
3. 可以自定义，名称：qwen3.8-27b;
4. 提供方，选择MiniMax;
5. 模型：qwen3.8-27b;
6. 选择免费的或者自己购买的API key；
7. 输入对应的Base URL；
8. 点击测试连接，显示成功即可。

**步骤六：通过对话方式，访问数据库中的内容。**

1. 在对话框左下角可以选择对应的数据库源；
2. 在右下角，选择我们的大模型qwen3.8-27b；
3. 通过自然语言创建数据库并插入数据，提示词：创建一个数据库students，并向里面插入10条数据；
4. 复制生成的SQL代码并运行即可；
5. 其他类似的需求提出自己问题即可。
